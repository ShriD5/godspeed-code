Only here

Not in T3 Code or Zeron.

Five things we checked against both codebases before claiming them.

01

Mission Control

Every agent on every device, on one board.

Cmd+Shift+K opens a board with each agent's status, elapsed time, latest activity, branch and diff counts. Move with the arrow keys, open a chat with Return, approve the low-risk ones with A.

02

Approvals ranked by risk

The safe ones go with one key.

Every approval and question from every agent lands in one Needs-you inbox. Godspeed reads the actual command: read-only commands and edits inside the chat's own folder are low risk. Network calls, git push, .env files and anything outside the repo are high, and always show you the full command.

03

Receipts with tokens

Every turn's tokens, on a receipt.

Each finished turn prints a receipt: wall time, tool calls by kind, files changed, and tokens in, out and cached. On API-billed accounts it adds an estimated cost. Copy it as text or as an image.

04

A Telegram bot for your zoomies

Schedule, steer and approve from your phone.

Zoomies are agents that run on a schedule, a webhook or a file change. The engine serves a Telegram bot, so you can schedule one, run it now, pause it and answer its approvals from Telegram, even when the engine lives on a server.

05

An animated Dock buddy

Your Dock icon runs with your agents.

The speedster jogs while agents work, sprints at four or more, waves when something needs you, celebrates a finish and naps after ten quiet minutes. Try it here. Settings → Appearance turns it off.

Checked against T3 Code (origin/main 40d335a7) and Zeron (upstream/main 8b7afb30) source on 28 October 2026. Scheduled agents and agents driving the preview browser exist in T3 Code too, so they aren't on this list.

Also shipping

Everything else that's in the box.

  • Conductor

    One long-lived chat plans the work and steers sub-agents. Each one gets a card, and the parent wakes when a child finishes, fails or needs you.

  • Zoomies from Home

    Hit the bolt in the new-chat composer, type "weekdays at 6pm", see the next run, send.

  • Run on a server

    Install the headless engine on a Linux box over your own SSH or Tailscale. Agents keep going with the laptop shut.

  • ACP registry agents

    Copilot CLI, Factory Droid, Gemini CLI and Kimi install in one click, each pinned to a checksum.

  • Several accounts per agent

    Named instances with their own config dir, env and account. Secrets go to the keychain.

  • Add a project to another device

    Clone a project onto your server or another Mac and bring the .env files git doesn't track, through your own signed-in engines.

  • Sub-agent worktrees

    Sub-agents can start in a fresh worktree on their own branch. Cleanup never touches unpushed work.

  • PR review and merge

    Approve, comment, resolve threads and merge from the PR pane, with GitHub's reason when it refuses.

  • PR watch

    Failed checks, new review comments and merge conflicts wake the PR's chat. Nothing is approved for you.

  • Usage meters

    Live 5-hour and weekly limits for every account, a tachometer in the composer, and history at API prices. Limited chats resume when the limit resets.

  • In-app updates

    Downloads, checks the signature and notarization, then asks you to restart. Never a downgrade.

  • Shared build slots

    Parallel agents share one jobserver. In testing, peak memory went from 4.7 GB to 2.0 GB.

  • iPhone app

    Follow your Mac's chats, approve, and dictate from your phone. Build it yourself for now.

  • Move in

    Import chats from T3 Code, Claude Code, Codex and Cursor. Claude Code and Codex sessions carry on.

  • Local by default

    No account needed. Chats live on your Mac, searchable from a local index.

What you need.

No pricing page, because there's no price.

A Mac with Apple silicon
M1 or later. Tested on macOS 27; the app declares macOS 12 as its minimum.
Your own agents
At least one agent CLI, signed in with your own account. Settings → Providers can run the installer for most of them.
Money
None. Godspeed is free and MIT-licensed. You keep paying for your agent subscriptions, and nothing else.
Linux
x86_64 and arm64 builds exist but are new and lightly tested. The same tarball runs the headless engine on a server.
Windows
Not yet.
iPhone
The app exists but isn't on TestFlight yet. Build it from source with Xcode; it needs cloud sync.
Sync
Off by default. Cloud sync is invite-only for now, or run your own sync server on Cloudflare.
Privacy
One anonymous usage ping a day, never prompts, code or paths. Turn it off in Settings → General. What's sent
